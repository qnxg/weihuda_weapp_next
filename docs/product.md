# 产品与接口设计

## 产品定位

“微生活”面向湖南大学学生，核心任务是快速查看今天和本周的课程，同时集中承载校园卡、成绩、考试、宿舍、校园网、体测、实验等查询服务。应用直接进入可浏览的移动端壳层，不设置营销落地页。

## 信息架构

### 一级导航

1. **今日**：展示当前月日与星期、当前学期与周次、校园公告、今日/明日课程、假期与学期倒计时、校园账户，考试、实验和体测预约摘要，以及当前学期课程成绩；通知入口位于顶部左侧并通过数字角标显示未读数量。
2. **课表**：学期与周次切换、周课表、无课表课程、自定义课程管理。
3. **服务**：只承载校园事务查询。学习类服务按“课程与考试”“实验”“体测”三个并列分区展示，校园生活类查询独立为一个分区。
4. **我的**：以姓名、学院、学号和头像展示账号身份，并提供积分中心、通知与设置、问题反馈、关于微生活和退出登录；不展示其他学籍信息。

今日、关于微生活、校历、登录后的课表与我的，以及以浏览远端数据为主的服务详情支持下拉刷新。刷新区域从页面标题栏下方开始；存在主 Tab 或顶层分段筛选时进一步限制在当前内容面板，标题与 Tab 始终保持原位。请求期间目标区域显示骨架，完成后恢复最新数据，同时保留各区块原有的错误和重试反馈；服务目录、设置、反馈、成绩排名和空教室等静态、编辑或显式条件查询页面不启用。

学习服务将“课程成绩”和“成绩排名”作为两个独立入口，两个详情页的标题栏均不显示副标题：`/services/grades` 在成绩列表标题展示当前学年学期，通过与课表页一致的弹窗切换服务端学期表中的可见项并查看课程成绩与构成明细；`/services/rank` 的教务系统排名在一张列表卡片中展示学年学期、课程范围、数据来源和成绩取值，其中学年和该学年下服务端可见的学期在同一弹窗的左右两列中联合选择。左列切换具体学年后继续选择右列学期，点击任一学期即完成并关闭弹窗；选择“全部学年”则直接完成为“全部学年 全部学期”。另外三个二选一条件直接通过卡片内 radio 切换。所有选择只更新筛选草稿，点击卡片下方的“查询”按钮后统一请求；可信电子凭证排名独立展示并支持更新。旧的成绩页排名查询链接会重定向到独立排名页。

体测服务拆分为三个独立入口：`/services/gym/grade` 的标题栏只显示“体测成绩”，正文从 `GET /semester` 的可见学期目录按服务端顺序去重得到可选学年，默认使用 `now_xn`，并通过“切换”弹窗选择当前或历史学年；历史选择写入 `?xn=`。页面先在总评卡中只展示总评分数和等级，其后不显示“单项成绩”标题，直接以带阴影的两列网格卡片展示七项成绩与第八项“视力”；每项以秒数、米数、次数等具体成绩作为加粗主信息，分数和固定项目占比作为次要信息，`rank` 用作等级标签文字并与次要信息保持 `4px` 上间距，`color=green` 使用 success 色、`color=red` 使用 error 色，其他值保持中性。单项成绩网格下方使用独立列表卡，按“成绩状态、成绩类型、成绩描述”三行展示 `report_status/report_type/report_description`，状态与其他值使用相同的普通文字样式，不使用标签；这些字段不在总评卡中重复出现。点击视力项打开弹窗查看裸眼视力、戴镜视力和屈光状态的左右眼数值与描述。`/services/gym/appointment` 独立请求并展示预约日期、时段、测试类型与状态。公开页面 `/services/gym/standard` 不发起接口请求，顶部总分卡标题区只显示“总分构成”，公式将标准分、附加分和总分名称放在对应数字下方，展示“100 + 20 = 120”，不显示额外三级说明；其后展示按总分评定的等级区间，“总分构成”“等级划分”和“项目评分标准”统一使用相同的 `16px` 分区标题，前两个标题行高度均为 `52px`。总分与等级后单独展示毕业成绩评定：毕业成绩由毕业当年学年总分的 `50%` 与其他学年总分平均得分的 `50%` 相加得到，毕业成绩和毕业等级均按该结果评定。性别、年级和测试项目统一位于一个“项目评分标准”分区内，该标题行不显示附加标签；性别与年级使用第一张卡，两个筛选行均为 `52px`，每组选项使用原生 radio 和可见圆形选择标记，标签保持至少 `44px` 点击高度。测试项目单独使用宽于内容视口的第二张白色卡片，卡内不显示标题、权重合计或内边距，只保留贴边排列且仅含图标与项目名的七个项目 Tab；选中项以品牌色图标和文字配合底部横线 indicator 标识，不使用填充底色，用户左右滚动时整张项目卡一起移动。七个项目按体重指数、肺活量、50 米跑、坐位体前屈、立定跳远、力量项目和耐力跑排列，对应权重为 `15%`、`15%`、`20%`、`10%`、`10%`、`10%`、`20%`；当前标准标题下方只显示所选项目的“占比 x%”，标题右侧不显示权重标签；项目单位只在表格“成绩要求（单位）”列标题中显示，计分方向不再显示。项目表格使用男、女生评分表中的实际数据，完整展示各性别和年级组对应的标准分档；耐力跑与力量项目达到 100 分后的附加分按超过标准的秒数或次数计算。

体测标准页“毕业成绩”卡的标题行只显示“毕业成绩”，计算方法与等级评定说明由卡片正文完整承载。“等级划分”标题行的“按总分评定”靠右展示；性别与年级筛选复用成绩排名页的共享 Radio 交互，两行选项均靠右排列；标准表的“等级”列表头与等级内容统一右对齐，分值列只显示数字。项目卡由七个 Tab 自然撑宽，首尾留白保持对称。

体重指数（BMI）标准使用原评分表的身体分类而非通用分数等级，依次展示“正常、低体重、超重、肥胖”；低体重与超重分别占一行并共同对应 80 分。选择 BMI 时，结果区副标题在占比后继续展示“BMI 指标 = 体重 / 身高的平方”。

耐力跑和力量项目在标准分卡片后以 `16px` 间距追加独立“附加分”分区，标题下不显示副标题。分区内以 `8px` 间距并列两张等宽卡片，第一张展示 `+10` 至 `+6`，第二张展示 `+5` 至 `+1`，每张固定 5 档；两张卡片左右外侧的内容边距与上方标准分卡片统一为 `14px`。成绩要求直接展示当前性别和年级组取得对应附加分所需的具体时间或次数，不再展示相对 100 分标准的秒数或次数差值。

实验服务拆分为两个独立入口：`/services/lab/schedule` 只请求实验安排，并保留用于同步安排与成绩的实验平台账号绑定表单；`/services/lab/grade` 复用可见学期目录，默认展示服务端当前学期，并可通过共享学期选择弹窗查看历史学期，独立请求并展示课程总评、实验出勤、评分项数量和评分组成。

校历是无需登录的学习服务。`/services/calendar` 通过公开 `GET /calendar` 获取按学年分组的阶段目录，再通过公开 `GET /calendar/{id}` 获取所选阶段的起止日期、前置参考周和安排说明。标题栏不显示副标题；正文标题直接使用详情 `name`，下方副标题显示“起止日期 共 N 周”，右侧“切换”按钮打开标题为“切换”的左右双列学年与学期联合选择弹窗。弹窗不显示列标题、“当前”、英文名或周数，只通过主题浅底标识选中项。页面 URL 仅使用稳定 `?id=` 保存非当前阶段选择；日期卡片由详情 `from/to/prev` 生成周日至周六的完整网格，之后按顺序展示 `notes` 中的考试、选课、开课、军训、春节和实践教学等说明。

成绩排名页在教务系统来源下说明“数据来源于教务系统。”；在可信电子凭证来源下说明“数据来源于可信电子凭证。数据并非实时更新。”。

课程成绩 item 在课程名下仅展示课程代码和学分。标签按成绩标识、辅修、课程类型 1、课程类型 2 的顺序展示：主修和空成绩标识省略，非空成绩标识使用 warning 色，辅修使用 success 色；“必修”课程类型 1，以及“专业课、专业基础、学类核心、学门核心、专业核心”课程类型 2 使用 primary 色，其余课程类型保持中性。同名标签只保留优先级最高者；右侧依次显示成绩和固定一位小数的绩点，界面不重复显示 `GPA` 字样。

课程成绩列表下方以小字说明“数据来源于教务系统。”、“点击可查看课程成绩的具体组成。”和“课程分数下方的小数为该门课程的绩点。”。

课程成绩详情弹窗只以课程名作为标题，成绩组成使用无卡片的分割线列表。组成项按“其他、平时、期中、期末”的阶段顺序展示，同一阶段内按名称字典序排列。

考试安排页标题栏不显示副标题，正文使用“未结束”和“已结束”两个不显示数量的 Tab 展示相互独立的考试纸片。两个 Tab 分别消费 `GET /exam` 的 `type=recent` 与 `type=end` 结果，保持接口返回顺序且不在前端重新分组；已结束列表通过当前已加载条数作为 `offset` 请求后续页面。纸片按三行双列组织：日期与状态、课程名与“考场 · 座位号”、课程号或自定义来源与考试时间；课程号旁不展示校区，超长课程名和考场名在各自列内换行，第二行较矮的一侧相对较高的一侧垂直居中。接口返回 `invalid: true` 的失效安排标记“已失效”，正常结束项目标记“已结束”，两种状态保持明确区分。未结束的自定义考试可编辑或删除；已结束和已失效的自定义考试禁用编辑，但仍可删除。新增入口只在“未结束”列表顶部显示为紧凑整宽卡片按钮，加号图标和“添加”文字同排居中，不占用页面标题栏。两个 Tab 的页尾均说明非自定义考试来自教务系统；已结束页额外解释考试信息变更或进入新学期可能使旧安排不存在，因此微生活将其标记为“已失效”。

校园公告只在登录态首页展示，不提供服务目录入口或独立详情页。首页不再展示“校园速览”，旧 `index_card` 摘要类 key 仅保留接口兼容。

### 匿名体验

- 匿名用户可以进入四个一级页面，查看应用外壳、公开元数据和全部服务入口。
- 需要个人数据的区域显示用途明确的登录门禁，不制造空白页。
- 登录门禁采用开放状态布局，并提供“去登录”文本操作，不将不可用内容包装为卡片。
- 匿名首页沿用登录态的日期标题栏和内容顺序；公开的学期周次与倒计时正常展示，课表、校园网、考试、通知和个性化卡片在原位置显示登录入口。
- 匿名首页的今日/明日课程 Tab 保持可切换，面板根据所选日期显示对应的登录提示，但不请求个人课表。
- 服务目录不使用锁图标区分鉴权状态；匿名用户点击受保护入口后仍进入登录流程并保留返回地址。
- 登录和匿名反馈无需鉴权。
- 登录后返回原访问位置。
- 登录页只保留左上角返回按钮、居中标题与两条字段，不使用品牌标志块；字段名以行内图标和占位文案呈现，字段错误紧贴对应输入框下方，页面不新增忘记密码、第三方登录或注册入口等当前不存在的文案。

| 通知       | `GET /notice`                          | 首页标题栏显示未读角标；通知页按状态展示完整内容       |
| 通知       | `PUT /notice/{id}`                     | 标记通知已读                                           |
| 教学楼     | `GET /building`                        | 展示楼栋描述、用户收藏状态、最近查询时间与完整楼栋目录 |

| 空教室     | `GET /empty_room`                      | 按多选小节次查询共同空闲教室并记录楼栋最近查询时间     |

## 状态与边界

- 首页课程以实际节次时间判断状态：上课前 20 分钟进入“即将开始”，开始后为“上课中”，结束后为“已结束”，其余为“未开始”。
- 今日有课且全部结束后，首页课程默认展示明日；用户仍可手动切回今日。
- `GET /calendar` 只返回按学年分组的 `items` 和服务端指定的 `now_id`；每个学年项的 `xn` 是完整可见名称，每个 `periods[]` 条目只包含稳定正整数 `id` 和中文 `name`，`now_id` 必须指向其中一个阶段。`GET /calendar/{id}` 只返回 `from/to/name/prev/notes`：`name` 作为页面标题，`from` 必须是正式阶段首周周日，`to` 必须是末周周六，`prev` 用唯一负整数偏移及显示名称描述前置参考周，`notes` 提供有序中文说明。页面 URL 只以 `?id=` 保存非当前选择；联合选择弹窗切换学年时只替换列表内已有的右列阶段，不发起详情请求，选择具体阶段后才提交对应 ID。前端从 `from` 到 `to` 按七天生成正式周次并从 1 编号，再按 `prev.index` 生成参考周；不得根据本地节假日或学年规则改写边界、名称或说明。详情加载和错误只替换日期与说明区域，已成功的阶段目录与切换入口持续可用。白色日期区无四周内边距，“周”与周日至周六的中文标题统一使用黑色；周数轴右侧使用细分割线与日期区分隔。月份提示位于日期数字下方，仅设备当前年月的日期数字保持正常文字色，其他月份弱化。前置参考周显示灰色背景，不显示“参考”文字，但无障碍名称保留参考周状态。卡片尾部使用 Primary 实色背景和白色文字展示中文安排说明；`notes` 为空时不渲染空说明区。校历是公开远端数据详情页，匿名状态可直接访问并支持下拉刷新；刷新边界位于正文联合筛选标题下，只替换日期与说明区域。
- `GET /semester` 返回的 `SemesterTable.items` 是用户可见学期的唯一目录，`now_xn/now_xq` 是当前学期的唯一依据；所有业务接口中的整数 `xq` 必须与 `SemesterItem.xq` 对应，界面中的学期名称直接使用 `SemesterItem.xq_text`。客户端不得根据 `xq` 拼接名称，也不得根据当前日期或学期日期范围自行改选当前学期。
- 登录态首页加载时与其他请求并行获取公告，在整个今日/明日课程区块之前按接口顺序展示全部返回项；公告卡只有“公告”标题栏保留品牌蓝背景，公告内容使用白色背景、中性分割线和深色正文。公告区只显示一个公告图标，每条公告展示发布时间并完整保留正文换行，空列表不占位，公告加载或失败不遮蔽课程，且不再提供独立校园公告页面。
- 周课表通过标题栏左侧按钮打开学期选择弹窗，按接口顺序列出 `SemesterTable.items`，展示“学年 + `xq_text`”、日期范围及当前学期文字状态，选中项仅使用主题浅底；并按周日至周六和第 1 至第 12 节排列。标题栏同时提供添加课程入口，周次标题左对齐、旁边显示学期总周数，切周按钮位于最右侧并在首周、末周分别禁用。课表区域没有横向溢出时可左滑进入下一周、右滑返回上一周；需要横向滚动的小屏继续优先滚动课表。服务端指定的当前学期尚未开始时默认显示首周，当前日期晚于其结束时间时默认显示末周；历史学期默认从首周展示。星期栏到达标题栏后共同吸顶，并在标题副标题中补充当前查看周次。连续记录仅在节次以外的所有课程字段完全一致时合并；地点、教师、周次或其他字段不同均保持为独立课程块。同一时段存在多门课程时优先展示当前周课程；仅当前查看周实际同时上课的课程计入左下角无背景 `+N` 文字，其他周次共用该时段不计入，右下角继续显示课程栈折角。课程详情使用居中纵向彩色卡展示课程类型、课程号、课程名、地点校区、班级、教师、周次、学分、人数与完整备注；详情不显示关闭按钮，通过卡片外遮罩或 Esc 关闭，内容过长时可在卡片内纵向滚动。冲突课程可横向滑动查看；非本周课程详情使用纯中性灰卡，不在正文重复显示“第 x 周不上课”，该状态仅保留在无障碍名称中。课程颜色按课程名称确定：非自定义课程名去重并按字典序排列在前，自定义课程名去重并按字典序排列在后，再沿调色板循环分配；同名课程始终使用同一颜色。开启“显示非本周课程”时，课程保留在原网格位置并显示“非本周”状态。
- “无课表课程”成功返回空列表时整个区块不显示；存在数据时列表以分割线组织，列表项只展示课程名称、课程性质、上课校区和教师。点击后在弹窗中查看课程类型、课程号、班级、校区、教师、学分和人数；`extra` 有内容时继续展示备注，为 `null` 或空字符串时省略整行。详情字段以分割线组织，超长备注使用全宽左对齐布局完整换行，并可通过触摸或键盘滚动弹窗正文查看。课表页末尾以六条小字说明本科生、研究生与未登录缓存的数据来源，课程详情入口，缓存与下拉刷新，无课表课程定义，彩色/灰色/叠角/`+N` 的含义，以及隐藏非本周课程的设置路径。
- 课表课程格使用 `11px` 课程名和 `9px` 地点、状态及冲突标记，并始终同时展示课程名称和地点，包括只占一个小节次的课程。地点固定显示一至两行；单节课程名称最多两行，单节且非本周时最多一行并继续显示状态文字，多节课程名称最多五行；任一字段超出可用行数时以省略号结束，点击后在详情中查看完整内容。所有课程格使用相同的顶部内边距并从顶部向下排列，不因仅占一个节次而垂直居中。
- 首页“倒计时”始终展示学期倒计时，仅当 `GET /countdown` 返回非空 `holiday` 时在其上方展示假期倒计时；状态与剩余自然日均由服务端按 `Asia/Shanghai` 计算，客户端不自行维护节假日或推导学期边界。
- 首页“校园账户”固定排列在倒计时之后、近期事项之前。首张整宽校园网卡展示本月流量和账号状态，其下三张等宽卡片展示未读邮件、宿舍剩余电量和校园卡金额；卡片高度限制在 `96px–120px`，宽度落在区间内时保持方形，超出时以最小或最大高度变成长方形。四项数据独立加载和恢复。
- 首页“近期事项”获取考试、实验和体测预约接口的全部记录，筛选尚未过期且距离今天不超过 6 个自然日的所有项目，按日期时间合并排序，因此列表可以包含任意数量及重复类别。每项左侧使用状态条和对应浅色背景：今天及 1–2 天为 Warning，3–4 天为 Success，5–6 天为白底中性条；列表项上方只显示“考试”“实验”“体测预约”，不重复“近期”。副标题统一显示不含年份且使用半角括号的“`M月D日(星期X)`”，并按接口实际提供内容继续追加时间段和地点，各段使用全角竖线 `｜` 分隔。未读通知移到左上角通知图标的红色数字角标，数量为零时不显示，超过 `99` 显示 `99+`。
- 首页彻底移除“校园速览”标题、版本信息和积分/动态/考试倒计时/最新成绩列表，改为固定“课程成绩”分区。该分区只请求服务端指定当前学期，标题不显示副标题；接口返回的全部课程按原顺序组成可自由左右滑动且不自动吸附的方形卡片轨道。轨道横向贯通应用宽度，首尾卡片与应用边缘各保留 `16px` 内边距；每张卡片只展示课程名称和成绩，点击任一卡片进入课程成绩页。
- 首页“近期考试”直接展示 `GET /exam?type=recent` 返回的第一项；失效安排和已结束安排通过 `type=end` 只在考试安排页的“已结束”Tab 中查看。
- 积分中心、问题反馈和关于微生活的目录入口统一放在“我的”页，服务目录不重复展示；首页仍可按个性化设置显示积分摘要，积分中心保留既有深链以兼容历史地址。
- “我的”页只消费 `GET /me` 的姓名、学院与学号作为可见身份信息，不展示班级、专业、入学年份、学制或性别；顶部身份区从页面顶部横向铺满应用宽度，标题栏与姓名区域使用连续深色背景，学号号码不带标签并以小字显示在姓名下方；学院单独位于下方白色区域，姓名首字头像跨压在两色分界线上。
- 匿名首页不请求受保护接口；每个依赖个人数据的首页区块独立显示登录说明与按钮，登录后返回首页。
- 列表无数据时提供与业务对应的空状态，不显示空容器。
- 外观跟随设备系统浅色/深色设置自动切换，不提供主题设置项；两种外观下同一份信息架构、鉴权边界和交互反馈保持一致，深色下正文、次要文字、语义标签与课程格子均保持可读对比度。
- 首页日期由本地时间直接显示；学期接口指定当前学年学期并补充周次，失败时省略该副标题。
- 排名结果区以当前学年学期作为标题，学年与学期仅以空格分隔；副标题显示课程范围、数据来源和成绩取值，并使用两侧留有空格的斜杠分隔。结果卡片的标题区域直接使用紧凑 Tab 切换全部、必修和核心课程，不再重复显示课程类型标题或数据存在状态提示；卡片正文按算术平均、加权平均和绩点三条指标展示。成绩与排名同时存在时保持左右布局，仅有一种数据时改为左对齐。普通成绩除 `100` 外固定保留两位小数，绩点固定保留一位小数；排名拆分为名次、弱化的总人数和括号内排名百分比。四种数据存在状态复用同一面板布局，只显示后端实际提供的数据；两类数据均缺失时显示“暂无成绩与排名数据”，不使用占位符伪造缺失内容。
- 空教室页标题栏不显示副标题；教学楼和日期集中在一张筛选列表卡中，不在筛选卡内提供节次字段，查询按钮独立放在卡片下方，与成绩排名页保持一致。页面进入后请求 `GET /building`，默认选中 `last_query_at` 最新的楼栋；没有查询历史时默认选中接口列表第一项，后续刷新不覆盖用户手动选择。页面按 `last_query_at` 倒序在教学楼字段内部以标签展示最多三个最近查询楼栋，点击标签直接切换当前选择并显示对勾；无查询历史时不显示标签区，不足三个时不补占位。页面不允许手输楼栋 ID，当前选择行和选择弹窗均不展示内部 ID；选择弹窗不显示搜索框和楼栋总数副标题，收藏楼栋固定排列在其他楼栋之前，并通过 `PUT /building/{building_id}/favorite` 即时收藏或取消收藏。弹窗名称下方仅展示接口非空的 `description`；北校区信息和“可能无法查询到数据”提示均以该字段为准。首次查询默认提交第 1、2 小节；`GET /empty_room` 接收楼栋、日期及必填的 `times` 小节次逗号列表，并返回同时满足全部所选节次的单个 `time/items` 结果。查询后的结果区以楼栋名称为标题、所选日期为副标题。页面使用左右两张独立卡片：左卡沿用原有 `80px` 纵向节次条，以节次范围和起止时间展示六组可查询时段；每组是可同时激活的无 checkbox 按钮，选中状态通过左侧指示条、表面和文字共同表达，至少保留一组。修改选择后立即以已提交的楼栋和日期重新查询。右卡按内容自然高度展示教室列表，不与左卡强制等高；加载、失败和无匹配教室只替换右卡内容，左侧选择持续可用。楼栋列表的加载、失败与重试限制在其消费区域内，日期和既有查询结果保持可用；成功查询后服务端更新该楼栋的最近查询时间，客户端刷新楼栋元数据。
- 空教室查询结果的副标题在已提交日期后显示对应星期，格式为“`YYYY-MM-DD 星期X`”。
- 没有参数或业务顺序依赖的请求并行加载；任一请求的加载、失败与重试只占用直接消费它的最小区块，不遮蔽页面壳、筛选器或其他成功内容。
- 页面级错误仅用于唯一核心数据源失败且页面没有可独立展示内容的场景；多请求页面使用区块级错误并只重试对应请求。
- 局部操作只锁定触发控件，不冻结同页其他查询与操作。
- 后端长文本最多展示 2 到 4 行，详情区允许完整换行；标识符和数值不被挤压。
- 删除、兑换、解绑等不可逆操作使用确认对话框。
