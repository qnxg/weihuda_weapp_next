# 移动端设计系统

## 设计方向

应用以“课程时间”为视觉识别：首页使用横向占满的课程状态卡，起止时间形成固定纵轴；周课表保留时间轴，帮助学生在移动中快速确认下一节课。其余页面采用清晰的分组列表和数据行，避免把每段内容都包装成装饰卡片。

视觉语言采用轻量 Material Design 2：画布、内容面和浮层具有明确但克制的高度关系，独立信息使用低层纸片，连续内容使用开放列表。纸片通过极轻阴影、遮挡和按压状态表达层级，不同时叠加高对比描边与重阴影。

这一方向与通用 SaaS 仪表盘不同：不使用渐变、巨型数字、悬浮卡片墙或装饰插画；视觉强调来自真实课表数据、校园红状态标记和可感知的交互反馈。

## 色彩

品牌色与语义色使用一致的五阶结构。`-2` 用于状态底色，`-1` 用于边界和低强调元素，`Base` 用于图标与文字，`+1` 用于悬停和按压，`+2` 保留给最高对比内容。各语义基色以接近的感知明度和克制度保持同一视觉重量。

| 色组      | -2        | -1        | Base      | +1        | +2        |
| --------- | --------- | --------- | --------- | --------- | --------- |
| `brand`   | `#fcebea` | `#eab3b1` | `#c13432` | `#972826` | `#6f1d1c` |
| `warning` | `#fff4e2` | `#e7c58f` | `#946017` | `#71470e` | `#4d3008` |
| `success` | `#eaf4ef` | `#acccbc` | `#367356` | `#285a43` | `#193e2d` |

| 令牌          | 色值       | 用途                       |
| ------------- | ---------- | -------------------------- |
| `brand`       | `#c13432`  | 主操作、选中导航、错误状态 |
| `brand-dark`  | `brand +1` | 按压态与高对比文字         |
| `canvas`      | `#f7f8fa`  | 应用背景                   |
| `surface`     | `#ffffff`  | 页面内容面                 |
| `ink`         | `#25272b`  | 主文本                     |
| `muted`       | `#6b7078`  | 次要文本                   |
| `line`        | `#e8eaee`  | 分割线                     |
| `line-strong` | `#cfd3da`  | 输入边界                   |
| `success`     | `#367356`  | 上课中、正常、完成、充足   |
| `warning`     | `#946017`  | 临近、待处理、余额偏低     |
| `info`        | `#246b8e`  | 信息型图标与提示           |

错误提示与破坏性操作直接复用 `brand` 色阶，不维护独立错误色。课程卡仅为“即将开始”和“上课中”在右侧显示提示文字，“未开始”和“已结束”不重复显示；全部状态文案仍保留在卡片无障碍名称中。视觉同时使用表面、侧边条和文字强度区分状态。主题红只用于主操作、当前位置、错误状态和关键数字；蓝、绿、黄不用于无语义的装饰性铺色。

## 字体

- 中文优先使用 `PingFang SC`、`Microsoft YaHei`，回退到系统无衬线字体。
- 正文 `15px / 1.55`，辅助文字 `13px / 1.45`。
- 页面标题 `22px / 1.3 / 700`，分区标题 `16px / 1.4 / 650`。
- 数据使用等宽数字特性 `font-variant-numeric: tabular-nums`。
- 不使用负字距、全大写装饰标签或随视口缩放字号。

## 空间与形状

- 基础空间单位为 `4px`，常用页面间距为 `16px`，分区间距为 `20px`。
- 控件最小触控尺寸 `44px`。
- 输入框和普通容器圆角 `6px`，模态对话框圆角 `8px`。
- 内容面依靠留白和分割线分组，仅重复条目或有独立语义的工具使用卡片。
- 内容纸片默认使用 `elevation 1`，按钮使用 `elevation 2`，悬停或键盘聚焦时可升至 `elevation 4`。
- 固定底栏使用向上的 `elevation 8`，模态底部面板和确认对话框使用 `elevation 24`。
- 空状态和登录门禁保持开放，不额外包裹纸片；独立工具和可点击服务入口保留纸片。

## 核心布局

```text
┌────────────────────────────┐
│ 通知  月日与星期             │
│       学年学期 · 加粗周次    │
├────────────────────────────┤
│ 今日课程  明日课程           │
│ ┃08:00  课程名称             │
│ ┃09:40  节次 | 教室 | 教师  │
├────────────────────────────┤
│ 倒计时  假期 2 天 / 学期 102 天│
├────────────────────────────┤
│ 近期考试 / 待处理事项        │
├────────────────────────────┤
│ 今日   课表   服务   我的    │
└────────────────────────────┘
```

- 页面使用不透明画布色、带轻量阴影的吸顶 App Bar，避免滚动内容透出；今日页通知入口位于左侧，日期和学期周次信息紧随其后。
- 匿名与登录态共用今日页 App Bar 和内容顺序，均展示公开的学期周次；通知图标沿用通知路由并由门禁保留登录返回地址。
- 首页课程日期标签栏与标题栏保持 `8px` 紧凑间距；登录与匿名态共用可点击、可键盘切换的今日/明日 Tab，匿名面板显示所选日期对应的登录门禁。
- 首页课程卡占满内容宽度，不显示卡片外时间轴；卡内时间列宽固定，正文列允许收缩并处理长文本。
- 首页同一天的课程 item 收纳在一个完整卡片中，仅列表容器保留圆角和一层阴影；item 间使用从内容区起始的 `1px` 分割线，不穿过侧边条。侧边条是与内容区分离的固定 `6px` 网格列，四种状态宽度一致且紧贴卡片外沿；未开始使用默认白色表面和 `line-strong` 中性条，已结束使用中性浅灰、弱化文字和更浅的 `line` 条；开课前 20 分钟使用 `warning` 浅底与侧条，上课中使用 `success` 浅底与侧条。
- 首页校园网摘要位于倒计时与近期事项之间：标题不显示副标题，已用流量和免费流量进度作为主信息，存在超额流量时在总用量右侧以小字显示；免费流量、账号状态、欠费使用等宽三列对齐，锁定和欠费同时独立显示，不以颜色作为唯一状态信号。
- 周课表使用“节次轴 + 周日至周六”八列网格，连续节次课程跨行合并；添加课程和切换学期使用标题左侧图标按钮，标题副标题显示“学年 + 学期”。周次使用左对齐普通分区标题，右侧紧随学期总周数，上一周和下一周按钮并排置于最右侧；该行保持 44px 触控高度，但将上下页面留白压缩到约 8px。星期表头下方保留课表网格内唯一分割线，其余节次和空格均不绘制分割线。所有空格统一使用白色；仅查看当前学期的当前周时，今天的星期表头使用主题色文字与 indicator，不使用整列底色。课程块使用六组低饱和背景和极轻阴影稳定区分课程，非本周课程同时使用中性斜纹和文字标记。`375px` 及以上视口完整显示七天，小屏仅允许课表容器内部横向滚动。
- 星期表头滚动至 App Bar 下方后与其共同吸顶：App Bar 阴影渐隐，星期表头阴影渐显，副标题平滑展开当前查看周次；离开课表区域或滚回顶部时恢复初始层级。
- 服务页图标统一使用 `brand-dark`，匿名态不在服务入口上附加锁图标；课程成绩与成绩排名使用两个并列入口，避免在详情页混合不同任务。
- 课程成绩页的 App Bar 不显示副标题；成绩列表分区以“学年 + 学期”为标题，右侧使用带日历切换图标的文本按钮打开共享学期选择弹窗，课程 item 之间使用 `1px` 分割线。教务排名页使用带可见标签的双列筛选网格，`359px` 以下切换为单列；选择“全部学年”时禁用无效的学期选择。排名结果按课程类型分组，使用“指标列 + 成绩/排名行”的语义表格；只渲染实际存在的数据行，两者均不存在时显示明确空状态，不使用破折号占位。可信凭证排名不重复显示分区标题，使用带刷新图标、操作标题和当前数据更新时间的整行纸片按钮发起更新。
- 页面内容底部预留导航高度与 `safe-area-inset-bottom`。
- 主视口最大宽度 `480px`，更宽屏幕居中显示，不承担桌面布局。
- 两列服务入口的标题与说明分别占行，卡片高度随内容自然增长；筛选表单可在窄屏退化为单列。

## 组件状态

- `Skeleton`：形状与最终内容接近，动画仅改变 opacity。
- `PageError`：说明具体问题，提供“重新加载”，必要时提供返回入口。
- `QueryState`：把骨架、失败提示和重试限制在直接消费该 Query 的区块；已有缓存内容时保留内容并附加刷新错误，不用整页状态覆盖其他成功区域。
- `EmptyState`：说明当前无数据及下一步，不使用情绪化文案。
- `AuthGate`：与错误状态一致地开放居中展示，不使用纸片、阴影或图标底色；操作文案固定为“去登录”，使用主色下划线文本按钮并保留至少 `44px` 点击高度。
- `InlineStatus`：保存、刷新、签到等局部操作使用 `aria-live="polite"`。
- `ConfirmDialog`：使用原生语义对话框，标题居中、说明左对齐；取消和确认操作等宽排列，确认操作使用对应语义色；请求进行中锁定两个操作并阻止退出。
- `Modal`：复杂表单使用底部浮层，标题栏固定、正文区域独立滚动，保留明确的关闭按钮和全宽主操作；点击遮罩可关闭，弹出时只使用短促的 opacity/transform 动画。
- `ChoiceCard`：整行可点击，标题和说明分层；选中时同时显示原生选择控件、左侧品牌标记和轻微表面变化。
- `CourseCard`：外层为单一卡片，内部课程项共享阴影并由细线分隔；每项首行使用常规字重显示开始时间和课程名，预警或进行中提示位于标题行末尾，次行单行显示结束时间、节次、地点和教师，超长元信息使用省略号。
- `ScheduleCourse`：课程名与地点在固定网格内截断，整个课程块为至少 `44px` 的详情按钮；详情使用底部 `Modal` 展示完整字段，自定义课程在详情内提供编辑和删除入口。
- `SemesterPicker`：课表和课程成绩页共享同一底部 `Modal`；课表标题栏使用日历切换图标按钮，成绩列表标题右侧使用图标加“切换”文本按钮。列表项标题为“学年 + 学期”，副标题显示日期范围，仅当前学期显示“当前”文字，选中项只使用主题浅底而不附加“已选”或对勾；调用方可配置支持的学期集合，长列表只滚动正文并保持弹窗标题栏固定。
- `CountdownOverview`：使用单张低层纸片和两行等宽数值区展示假期与学期倒计时；假期临近使用 warning 色、进行中使用 success 色，学期使用 info 色，完成或待公布状态回落为中性色；每行均以文字和数字共同表达状态。
- `NetworkOverview`：使用单张可点击纸片展示本月已用总量、免费流量进度及三列关键状态，不在“本月已用”前放置图标；进度不超过 50% 使用 success 色，超过 50% 使用 warning 色，超过 90% 使用 brand 主色，完整百分比和状态文字始终保留。
- 匿名首页保留课程日期标签和全部分区标题；公开倒计时完整展示，课程、校园网、近期事项和校园速览使用区块级登录门禁。
- 主按钮使用实色与低层阴影，次按钮使用中性填充或描边；同一操作区只保留一个高强调按钮。
- 可点击纸片：提供 hover、focus 和 pressed 状态；移动端按压使用状态层与轻微位移，不依赖 hover。
- 路由切换：仅对整页使用一次短促的 opacity/transform 过渡，不为每个区块添加进场动画。

## 可访问性

- 使用语义化标题、列表、表单、按钮和链接。
- 图标按钮具有 `aria-label`，装饰图标设置 `aria-hidden="true"`。
- 焦点环使用品牌色并保持 2px 可见边界。
- 支持系统减少动态效果设置。
- 页面提供跳转到主内容的隐藏链接。
- 不禁用缩放，不拦截粘贴；表单错误显示在字段附近。
