# 移动端设计系统

## 设计方向

应用以“课程时间”为视觉识别：首页使用横向占满的课程状态卡，起止时间形成固定纵轴；周课表保留时间轴，帮助学生在移动中快速确认下一节课。其余页面采用清晰的分组列表和数据行，避免把每段内容都包装成装饰卡片。

视觉语言采用轻量 Material Design 2：画布、内容面和浮层具有明确但克制的高度关系，独立信息使用低层纸片，连续内容使用开放列表。纸片通过极轻阴影、遮挡和按压状态表达层级，不同时叠加高对比描边与重阴影。

这一方向与通用 SaaS 仪表盘不同：不使用渐变、巨型数字、悬浮卡片墙或装饰插画；视觉强调来自真实课表数据、语义色状态标记和可感知的交互反馈。

## 色彩

品牌色与语义色使用一致的五阶结构。`-2` 用于状态底色，`-1` 用于边界和低强调元素，`Base` 用于图标、选中态和进度等品牌识别，`+1` 用于正文、实色按钮及悬停，`+2` 保留给按压和最高对比内容。各语义基色以接近的感知明度和克制度保持同一视觉重量。

## 字体

- 中文优先使用 `PingFang SC`、`Microsoft YaHei`，回退到系统无衬线字体。
- 正文 `15px / 1.55`，辅助文字 `13px / 1.45`。
- 页面标题 `22px / 1.3 / 700`，分区标题 `16px / 1.4 / 650`。
- 数据使用等宽数字特性 `font-variant-numeric: tabular-nums`。
- 不使用负字距、全大写装饰标签或随视口缩放字号。

## 空间与形状

- 基础空间单位为 `4px`，常用页面间距为 `16px`，分区间距为 `20px`。
- 控件最小触控尺寸 `44px`。
- 输入框和普通容器圆角 `6px`，模态对话框圆角 `8px`。
- 内容面依靠留白和分割线分组，仅重复条目或有独立语义的工具使用卡片。
- 内容纸片默认使用 `elevation 1`，按钮使用 `elevation 2`，悬停或键盘聚焦时可升至 `elevation 4`。
- 固定底栏使用向上的 `elevation 8`，模态底部面板和确认对话框使用 `elevation 24`。
- 空状态和登录门禁保持开放，不额外包裹纸片；独立工具和可点击服务入口保留纸片。

## 核心布局

```text
┌────────────────────────────┐
│ 通知  月日与星期             │
│       学年学期 · 加粗周次    │
├────────────────────────────┤
│ 今日课程  明日课程           │
│ ┃08:00  课程名称             │
│ ┃09:40  节次 | 教室 | 教师  │
├────────────────────────────┤
│ 倒计时  假期 2 天 / 学期 102 天│
├────────────────────────────┤
│ 校园账户                    │
│ 校园网 / 邮件 / 电量 / 校园卡 │
├────────────────────────────┤
│ 考试 / 实验 / 体测预约       │
├────────────────────────────┤
│ 当前学期课程成绩             │
│ 课程名 / 分数 / 绩点         │
├────────────────────────────┤
│ 今日   课表   服务   我的    │
└────────────────────────────┘
```

- 页面使用不透明画布色的吸顶 App Bar，滚动容器位于顶部时不显示阴影，开始滚动后以轻量阴影分隔下方内容；今日页通知入口位于左侧，日期和学期周次信息紧随其后。存在未读通知时，在 `44px` 图标按钮右上角显示最小 `18px` 的 Error 红色数字角标，使用白色等宽数字和画布色描边，超过 `99` 显示 `99+`。
- App Bar 右侧永久留空，页面标题组件不提供右侧操作槽。返回、通知和必要的上下文工具只能位于标题左侧；新增、重试、筛选等业务操作放在正文中，并与其影响的数据区块或列表相邻。
- 支持刷新的数据页在 App Bar 下方提供下拉刷新，App Bar 本身始终保持原位；存在主 Tab 或顶层分段筛选时，刷新锚点继续下沉到 Tab 或筛选控件下方，只移动当前内容面板。下拉过程中目标区域产生受阻尼限制的位移，中央 `40px` 圆形纸片依次显示下拉、刷新、完成或失败图标；请求进行中以区域骨架替换旧内容，骨架与指示器至少保留 `8px` 净间距。该反馈收起后不保留布局高度。横向手势、表单控件、弹窗和未处于滚动顶部的页面不触发刷新。
- 匿名与登录态共用今日页 App Bar 和内容顺序，均展示公开的学期周次；通知图标沿用通知路由并由门禁保留登录返回地址。
- 首页没有公告时，课程日期标签栏与标题栏保持与页面横向内边距一致的 `16px` 间距；登录与匿名态共用可点击、可键盘切换的今日/明日 Tab，匿名面板显示所选日期对应的登录门禁。
- 登录态首页公告位于整个今日/明日课程区块之前；标题栏、公告列表和课程区块之间均保持 `16px` 间距。公告卡只有顶部标题栏使用普通 Primary `brand` 的 `info-surface` 背景，单一图标使用 `brand -2`，“公告”标题使用白色且字号与“今日课程”和“倒计时”一致；标题栏下方的公告正文区统一使用白色表面。多条公告按接口顺序排列并使用中性 `line` 分割线区分；每条公告标题使用 `ink`，发布时间使用 `muted`，完整正文使用 `ink`，不截断多行内容。外链按钮位于正文行右侧，不参与标题和时间的列宽计算，使用 `brand-dark` 并保持至少 `44px` 触控区域。加载骨架同样使用蓝色标题栏与白色正文，骨架和分割线分别使用 `skeleton` 与 `line`；紧凑错误重试仍使用独立 Error 语义，空列表不保留空白。
- 首页课程卡占满内容宽度，不显示卡片外时间轴；卡内时间列宽固定，正文列允许收缩并处理长文本。
- 首页同一天的课程 item 收纳在一个完整卡片中，仅列表容器保留圆角和一层阴影；item 间使用从内容区起始的 `1px` 分割线，不穿过侧边条。侧边条是与内容区分离的固定 `6px` 网格列，四种状态宽度一致且紧贴卡片外沿；未开始使用默认白色表面和 `line-strong` 中性条，已结束使用中性浅灰、弱化文字和更浅的 `line` 条；开课前 20 分钟使用 `warning` 浅底与侧条，上课中使用 `success` 浅底与侧条。
- 首页“校园账户”位于倒计时与近期事项之间。校园网摘要作为整宽主卡，其下以 `8px` 间距并列未读邮件、宿舍剩余电量和校园卡金额三张等宽 Material 纸片；纸片高度限制在 `96px–120px`，宽度位于区间时保持方形，超出时钳制高度。
- 首页“近期事项”使用单张低层列表纸片承载合并排序后的全部近期项目，列表长度和同类项目数量均不固定。每个 item 复用今日课程的独立 `6px` 左侧状态条与背景：今天及 1–2 天使用 Warning 条和 `warning-soft`，3–4 天使用 Success 条和 `success-soft`，5–6 天使用白底与 `line-strong` 中性条。相邻 item 的 `1px` 分割线从状态条右侧 `6px` 处立即开始，不保留额外左侧空隙。每项上方弱化类别名按来源显示“考试”“实验”“体测预约”，主信息下方统一以 `11px` 弱化文字显示“`M月D日(星期X) ｜ 时间段 ｜ 地点`”，星期使用半角括号，并省略不存在的时间或地点段。右侧使用方向图标。加载和错误状态保持相同行高；无任何近期项目时显示单一整体空状态。
- 首页不显示“校园速览”。“课程成绩”分区标题不显示副标题，其下直接使用无外层卡片的横向自由滚动轨道承载全部成绩，不使用 scroll-snap 或停止后的自动对齐。每门课程使用固定 `104px × 104px`、`8px` 间距的独立低层 Material 方卡，只在上方展示最多三行课程名，在底部以品牌深色大号数字展示成绩；不显示学期、数量、课程属性、学分或绩点。轨道隐藏滚动条，以左右 `-16px` 外边距抵消页面内边距，使滚动区域沿应用 X 方向贯通；轨道内部首尾各使用 `16px` padding，为第一张和最后一张卡保留稳定边缘留白。每张卡片均可进入完整成绩页。
- 周课表使用“节次轴 + 周日至周六”八列网格；连续记录仅在节次以外的所有课程字段一致时合并，地点、教师或周次等任一字段变化都拆为独立课程块。添加课程和切换学期使用标题左侧图标按钮，标题副标题显示“学年 + 学期”。周次使用左对齐普通分区标题，右侧紧随学期总周数，上一周和下一周按钮并排置于最右侧；该行保持 44px 触控高度，但将上下页面留白压缩到约 8px。课表区域没有横向溢出时使用 `pan-y` 保留纵向页面滚动，并以超过 `48px` 且横向位移明显大于纵向位移的手势切周：左滑下一周、右滑上一周；存在横向溢出时恢复原生横向滚动。星期表头下方保留课表网格内唯一分割线，其余节次和空格均不绘制分割线。所有空格统一使用白色；仅查看当前学期的当前周时，今天的星期表头使用主题色文字与 indicator，不使用整列底色。课程名称按“非自定义课程在前、自定义课程在后”分组后分别按字典序排序，再循环映射到十组 `$course-cell-background-colors` 与 `$course-cell-text-colors`；同名课程始终使用同一组颜色，每组文字与背景对比度不低于 `4.5:1`，课程块不使用阴影。非本周课程同时使用中性斜纹和文字标记。单节与多节课程格使用相同顶部内边距并统一从顶部向下排列，不按高度垂直居中。同一星期与起止节次存在多门课程时只展示当前周课程；只有当前查看周至少两门课程实际同时上课时，左下角才以无背景 `+N` 文字标记其余在上课程数量，其他周次的课程不计入；右下角使用 16px 折角提示课程栈，折角下半部复用非本周课程的 `surface-muted` 背景。`+N` 预留独立底部空间，不得遮挡课程名、地点或非本周状态。课程详情使用居中的高纵向彩色卡，沿用课程名称对应的颜色索引映射到 `$course-detail-background-colors` 并使用白色文字；内边距为 `24px 24px 20px`，课程性质和课程代码使用 `12px` 字号，课程名与详情信息区间隔 `20px`。完整备注随其余字段自然换行，内容超过卡片高度时只滚动卡片内部，并使用半透明细滚动条与随位置变化的顶部/底部滚动阴影提示剩余内容。详情不显示关闭按钮，卡片外透明轨道区域视为遮罩并可点击关闭，同时支持 Esc。冲突课程组成横向 scroll-snap 轮播，下一张从右侧露出；非本周详情卡使用 `$course-detail-inactive-background`（`#707070`）纯中性灰，不在可见正文重复标注“不上课”，状态只保留在无障碍名称中；轨道上下留白必须完整容纳卡片阴影。`375px` 及以上视口完整显示七天，小屏仅允许课表容器内部横向滚动。

- 课程成绩属性与空教室最近楼栋统一使用共享 `Tag` 组件，复用胶囊圆角、语义色、内边距、字号和字重。空教室页标题栏只显示标题和返回按钮，不显示副标题。筛选器与成绩排名筛选器使用相同的信息结构：教学楼和日期集中在一张带行间分割线的列表表面中，不显示节次输入，字段名左对齐，当前值或输入控件右对齐，查询按钮独立置于卡片下方。教学楼默认显示最近一次查询的楼栋；没有历史时显示接口列表第一项。存在查询历史时，在教学楼字段的当前选择行下方使用紧凑 Material choice chip 展示最多三个最近查询楼栋；芯片固定为单行右对齐，每项最多占标签区三分之一，超长名称在芯片内省略并保留完整无障碍名称。按钮保持至少 `44px` 点击热区，共享标签表面固定为 `28px` 高，选中项使用主题浅底和前置对勾，无历史时不渲染标签区。教学楼当前选择行只显示楼栋名称，不显示内部 ID，并通过底部 `Modal` 打开完整列表。弹窗不显示搜索框、楼栋总数副标题和内部楼栋 ID，将收藏楼栋分组置顶；每行只展示楼栋名称与可选的弱化 `description`，右侧使用 `Star` 图标按钮收藏或取消收藏。选中楼栋只使用主题浅底，不显示对勾；收藏状态同时使用实心星标和无障碍名称表达，收藏请求失败在弹窗内显示。楼栋请求的骨架、错误与重试均限制在其消费区域内。结果区查询后以楼栋名称为标题、所选日期为副标题。查询结果使用并排的两张独立 Material 卡片并保持 `8px` 间距：左卡恢复原有 `80px` 纵向节次条，六个条目各保持至少 `60px` 高并分两行显示节次范围和时间段。条目使用无边框按钮和 `aria-pressed` 支持多项同时选中，不显示 checkbox；选中项使用左侧 `3px` 指示条、白色表面和品牌文字共同表达，未选项保留弱化文字与浅灰表面。右卡直接使用语义列表展示同时满足全部所选节次的教室，不设置重复摘要头、最小高度或与左卡强制等高，也不嵌套额外卡片。教室行重置标题默认 margin，并使用紧凑纵向内边距和行间分割线。修改选择时左卡保持稳定，右卡局部切换为骨架、错误或空状态。
- 空教室结果标题下的副标题使用单行弱化文字展示“`YYYY-MM-DD 星期X`”，日期与星期以一个空格分隔。
- 页面内容底部预留导航高度与 `safe-area-inset-bottom`。
- 主视口最大宽度 `480px`，更宽屏幕居中显示，不承担桌面布局。
- 两列服务入口的标题与说明分别占行，卡片高度随内容自然增长。

## 组件状态

- `Skeleton`：形状与最终内容接近，动画仅改变 opacity。
- `PageError`：说明具体问题，提供“重新加载”，必要时提供返回入口。
- `QueryState`：把骨架、失败提示和重试限制在直接消费该 Query 的区块；已有缓存内容时保留内容并附加刷新错误，不用整页状态覆盖其他成功区域。
- `PullToRefresh`：只用于直接展示远端数据且没有显式提交语义的页面；根据语义结构把刷新目标解析为标题下正文、顶层分段筛选后的结果区或当前 `tabpanel`。超过阈值后刷新当前页活跃 Query，刷新期间阻止重复触发、隐藏目标区域旧内容并展示骨架，通过 `aria-live` 播报进行中、完成和失败状态。服务目录、设置、反馈与显式条件查询页不启用。
- `PageHeader`：右侧始终为空且组件 API 不接受右侧内容；可选的返回、通知和上下文工具通过左侧 leading 区域与标题组合。
- `EmptyState`：说明当前无数据及下一步，不使用情绪化文案。
- `AuthGate`：与错误状态一致地开放居中展示，不使用纸片、阴影或图标底色；操作文案固定为“去登录”，使用主色下划线文本按钮并保留至少 `44px` 点击高度。
- `InlineStatus`：保存、刷新、签到等局部操作使用 `aria-live="polite"`。
- `ConfirmDialog`：使用原生语义对话框，标题居中、说明左对齐；取消和确认操作等宽排列，确认操作使用对应语义色；请求进行中锁定两个操作并阻止退出。
- `Modal`：复杂表单使用底部浮层，标题栏固定、正文区域独立滚动，保留明确的关闭按钮和全宽主操作；长内容场景为正文滚动区提供名称和键盘焦点，使 `PageDown`、方向键与 `End` 可访问全部内容；点击遮罩可关闭，弹出时只使用短促的 opacity/transform 动画。
- `ChoiceCard`：整行可点击，标题和说明分层；选中时同时显示原生选择控件、左侧品牌标记和轻微表面变化。
- `CourseCard`：外层为单一卡片，内部课程项共享阴影并由细线分隔；每项首行使用常规字重显示开始时间和课程名，预警或进行中提示位于标题行末尾，次行单行显示结束时间、节次、地点和教师，超长元信息使用省略号。
- `ExamCard`：每场考试独立成卡，正文严格使用日期/状态、课程/场地座位、元信息/时间三行双列网格，不插入图标或纵向字段列表；卡片字段允许在各自列内完整换行，所有时间和失效状态均有可见文字，不以颜色作为唯一状态标识。`ExamAddCard` 仅显示带无障碍名称的加号图标，并始终位于“未结束”考试列表末尾。
- `AcademicCalendarPeriod`：当前联合选择结果对应一个低层纸片，内部只排列由详情边界生成的完整日期网格和中文说明列表，不嵌套第二层卡片，也不重复页面筛选标题中的阶段信息。正式周次从 1 开始；前置参考周使用接口 `prev.name` 的短文本显示，并在行级无障碍名称中补充“参考周”状态。
- `ScheduleCourse`：课程格内课程名使用 `11px`，地点、“非本周”和 `+N` 使用 `9px`。课程名与地点始终同时显示在固定网格内，地点保留至少一行并限制为最多两行；单节课程名称最多两行，单节且非本周时为状态文字留位并收紧为最多一行，多节课程名称最多五行，两类文本溢出时分别显示省略号。整个课程块为至少 `44px` 的详情按钮，完整文本进入无障碍名称；详情使用居中的 `course-detail` Modal 展示完整字段和备注，不显示关闭按钮，自定义课程在详情内提供编辑和删除入口。
- `ScheduleExtraCourse`：接口成功返回空列表时不渲染标题、容器或空状态；存在数据时使用单一白色表面和 `1px` 行间分割线。每项采用课程名称与弱化元信息两层结构，列表只显示课程名称、课程性质、上课校区和教师，其他字段进入点击后的详情弹窗。弹窗中的相邻字段同样使用 `1px` 分割线；`extra` 无内容时省略备注行，非空备注独占一行并使用左对齐常规字重完整换行，内容超高时通过可聚焦的命名正文区域滚动。
- `SemesterPicker`：课表和课程成绩页共享同一底部 `Modal`；课表标题栏使用日历切换图标按钮，成绩列表标题右侧使用图标加“切换”文本按钮。列表严格保持 `SemesterTable.items` 的服务端顺序，不在客户端生成、补齐或按日期筛选学期；列表项标题为“学年 + `xq_text`”，副标题显示日期范围，仅 `now_xn/now_xq` 对应项显示“当前”文字，选中项只使用主题浅底而不附加“已选”或对勾。长列表只滚动正文并保持弹窗标题栏固定。
- `BuildingPicker`：空教室页加载完整楼栋列表，不提供搜索；收藏组始终位于其他楼栋之前，列表项保留至少 `56px` 高度，选择区域和 `44px` 收藏按钮相互独立，长名称与描述可换行，空描述不预留占位。选中楼栋只显示主题浅底和 `aria-pressed` 状态，不显示对勾；选择后关闭弹窗并把焦点恢复到触发按钮。
- `GymStandardTable`：标准分卡片保持“分值、成绩要求（单位）、等级”三列结构，按性别和年级显示男、女生评分表中的完整标准分档；常规项目展示 20 档，BMI 按原表分为“正常、低体重、超重、肥胖”四行，其中低体重与超重均为 80 分；低体重标签使用 Primary 色，超重使用 Warning 色。选择 BMI 时，当前标准副标题在占比后以中点分隔并展示“BMI 指标 = 体重 / 身高的平方”。男生引体向上按原表展示 15 档。耐力跑和力量项目在标准分卡片后以 `16px` 间距展示附加分分区，分区标题只显示“附加分”且无副标题；内部使用 `8px` 间距的等宽双列卡片，左卡展示 `+10` 至 `+6`，右卡展示 `+5` 至 `+1`，每张表固定 5 档并只保留“分值、成绩要求（单位）”两列。附加分卡片靠外边缘的表格内容与标准分卡片统一使用 `14px` 横向内边距，靠双卡中线的一侧保持紧凑。成绩要求直接展示当前性别和年级组的具体时间或次数门槛，不显示相对 100 分标准的差值。
- `CountdownOverview`：使用单张低层纸片和等宽数值区展示倒计时；学期行始终存在，假期行仅在接口返回安排时显示，不渲染“暂无后续假期”占位。假期临近使用 warning 色、进行中使用 success 色，学期使用 info 色，学期完成或待同步状态回落为中性色；每行均以文字和数字共同表达状态。
- `ProgressBar`：共享语义化 `progress` 控件统一使用 `6px` 高度、全圆角和中性轨道，通过 `primary / success / warning` 显式 tone 控制填充色；校园网摘要按用量阈值切换 tone，流量明细固定使用 primary。
- `NetworkUsageSummary`：首页校园网卡片与校园网页复用“本月已用”、总量、右对齐百分比和 `ProgressBar` 的同一信息层级；百分比不使用胶囊。进度不超过 50% 使用 success 色，超过 50% 使用 warning 色，超过 90% 使用 primary 色。校园网页标题栏不显示副标题，也不显示独立账号状态提示条及“本月用量”“账号信息”可见标题；下方四宫格按“上传流量 / 下载流量、免费流量 / 超出流量”的两行顺序展示。账号信息列表卡依次放置欠费金额、锁定状态、“历史账单”和“流量明细”，四项统一使用左侧图标与两级文案；前两项右侧显示状态值，后两项右侧显示箭头并进入独立页面。流量明细页的分区标题直接显示当前年月或具体日期，副标题只显示总流量；右侧复用课程成绩页的 `CalendarSync + 切换` 文本按钮打开日期弹窗，弹窗使用并排且带可见标签的年份输入与中文月份下拉，日期下拉首项固定为“全月”，其余选项按所选月份的实际天数生成。列表分类名称仅移除接口值最前方的一个 `/`，保留后续路径层级；路径内的 `/` 使用 `line-strong` 色和 `4px` 左右间距，列表项继续沿用共享列表的内边距与分割线。
- `NetworkOverview`：使用单张可点击纸片组合共享用量摘要与三列关键状态，不在“本月已用”前放置图标；完整百分比和状态文字始终保留。
- 匿名首页保留课程日期标签和全部分区标题；公开倒计时完整展示，课程、校园账户、近期事项和课程成绩使用区块级登录门禁。
- 主按钮使用实色与低层阴影，次按钮使用中性填充或描边；同一操作区只保留一个高强调按钮。
- 可点击纸片：提供 hover、focus 和 pressed 状态；移动端按压使用状态层与轻微位移，不依赖 hover。
- 路由切换：仅对整页使用一次短促的 opacity/transform 过渡，不为每个区块添加进场动画。

## 可访问性

- 使用语义化标题、列表、表单、按钮和链接。
- 图标按钮具有 `aria-label`，装饰图标设置 `aria-hidden="true"`。
- 焦点环使用品牌色并保持 2px 可见边界。
- 支持系统减少动态效果设置。
- 页面提供跳转到主内容的隐藏链接。
- 不禁用缩放，不拦截粘贴；表单错误显示在字段附近。
