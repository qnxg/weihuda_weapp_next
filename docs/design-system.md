# 移动端设计系统

## 设计方向

应用以“课程时间轴”为视觉识别：时间是固定锚点，课程信息沿纵向轨道排列，帮助学生在移动中快速确认下一节课。其余页面采用清晰的分组列表和数据行，避免把每段内容都包装成装饰卡片。

视觉语言采用轻量 Material Design 2：画布、内容面和浮层具有明确但克制的高度关系，独立信息使用低层纸片，连续内容使用开放列表。纸片通过极轻阴影、遮挡和按压状态表达层级，不同时叠加高对比描边与重阴影。

这一方向与通用 SaaS 仪表盘不同：不使用渐变、巨型数字、悬浮卡片墙或装饰插画；视觉强调来自真实课表数据、校园红状态标记和可感知的交互反馈。

## 色彩

品牌色与语义色使用一致的五阶结构。`-2` 用于状态底色，`-1` 用于边界和低强调元素，`Base` 用于图标与文字，`+1` 用于悬停和按压，`+2` 保留给最高对比内容。各语义基色以接近的感知明度和克制度保持同一视觉重量。

| 色组 | -2 | -1 | Base | +1 | +2 |
| --- | --- | --- | --- | --- | --- |
| `brand` | `#fcebea` | `#eab3b1` | `#c13432` | `#972826` | `#6f1d1c` |
| `warning` | `#fff4e2` | `#e7c58f` | `#946017` | `#71470e` | `#4d3008` |
| `success` | `#eaf4ef` | `#acccbc` | `#367356` | `#285a43` | `#193e2d` |

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `brand` | `#c13432` | 主操作、当前课程、选中导航 |
| `brand-dark` | `brand +1` | 按压态与高对比文字 |
| `canvas` | `#f7f8fa` | 应用背景 |
| `surface` | `#ffffff` | 页面内容面 |
| `ink` | `#25272b` | 主文本 |
| `muted` | `#6b7078` | 次要文本 |
| `line` | `#e8eaee` | 分割线 |
| `line-strong` | `#cfd3da` | 输入边界 |
| `success` | `#367356` | 正常、完成、充足 |
| `warning` | `#946017` | 临近、待处理、余额偏低 |

错误提示与破坏性操作直接复用 `brand` 色阶，不维护独立错误色。颜色不单独承担语义，状态始终同时提供文字或图标。主题红只用于主操作、当前位置、当前课程、错误状态和关键数字；蓝、绿、黄不用于装饰性铺色。

## 字体

- 中文优先使用 `PingFang SC`、`Microsoft YaHei`，回退到系统无衬线字体。
- 正文 `15px / 1.55`，辅助文字 `13px / 1.45`。
- 页面标题 `22px / 1.3 / 700`，分区标题 `16px / 1.4 / 650`。
- 数据使用等宽数字特性 `font-variant-numeric: tabular-nums`。
- 不使用负字距、全大写装饰标签或随视口缩放字号。

## 空间与形状

- 基础空间单位为 `4px`，常用页面间距为 `16px`，分区间距为 `20px`。
- 控件最小触控尺寸 `44px`。
- 输入框和普通容器圆角 `6px`，模态对话框圆角 `8px`。
- 内容面依靠留白和分割线分组，仅重复条目或有独立语义的工具使用卡片。
- 内容纸片默认使用 `elevation 1`，按钮使用 `elevation 2`，悬停或键盘聚焦时可升至 `elevation 4`。
- 固定底栏使用向上的 `elevation 8`，模态底部面板和确认对话框使用 `elevation 24`。
- 空状态保持开放，不额外包裹纸片；登录门禁、独立工具和可点击服务入口保留纸片。

## 核心布局

```text
┌────────────────────────────┐
│ 页面标题          消息/操作 │
│ 日期与学期信息              │
├────────────────────────────┤
│ 08:00  ● 课程名称           │
│        │ 教室 · 教师        │
│ 10:10  ○ 下一节课程         │
│        │ 教室 · 教师        │
├────────────────────────────┤
│ 近期考试 / 待处理事项        │
├────────────────────────────┤
│ 今日   课表   服务   我的    │
└────────────────────────────┘
```

- 顶部使用固定位置的轻量 App Bar；内容左对齐，时间列宽固定，正文列允许收缩并处理长文本。
- 页面内容底部预留导航高度与 `safe-area-inset-bottom`。
- 主视口最大宽度 `480px`，更宽屏幕居中显示，不承担桌面布局。
- 两列服务入口的标题与说明分别占行，卡片高度随内容自然增长；筛选表单可在窄屏退化为单列。

## 组件状态

- `Skeleton`：形状与最终内容接近，动画仅改变 opacity。
- `PageError`：说明具体问题，提供“重新加载”，必要时提供返回入口。
- `EmptyState`：说明当前无数据及下一步，不使用情绪化文案。
- `AuthGate`：说明登录后可见的内容与“登录”操作。
- `InlineStatus`：保存、刷新、签到等局部操作使用 `aria-live="polite"`。
- `ConfirmDialog`：使用原生语义对话框，标题居中、说明左对齐；取消和确认操作等宽排列，确认操作使用对应语义色；请求进行中锁定两个操作并阻止退出。
- `Modal`：复杂表单使用底部浮层，保留明确的关闭按钮和全宽主操作；弹出时只使用短促的 opacity/transform 动画。
- `ChoiceCard`：整行可点击，标题和说明分层；选中时同时显示原生选择控件、左侧品牌标记和轻微表面变化。
- 主按钮使用实色与低层阴影，次按钮使用中性填充或描边；同一操作区只保留一个高强调按钮。
- 可点击纸片：提供 hover、focus 和 pressed 状态；移动端按压使用状态层与轻微位移，不依赖 hover。
- 路由切换：仅对整页使用一次短促的 opacity/transform 过渡，不为每个区块添加进场动画。

## 可访问性

- 使用语义化标题、列表、表单、按钮和链接。
- 图标按钮具有 `aria-label`，装饰图标设置 `aria-hidden="true"`。
- 焦点环使用品牌色并保持 2px 可见边界。
- 支持系统减少动态效果设置。
- 页面提供跳转到主内容的隐藏链接。
- 不禁用缩放，不拦截粘贴；表单错误显示在字段附近。
